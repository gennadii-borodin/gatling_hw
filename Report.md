# Поиск максимальной производительности системы

## Max Performance Test (Максимальная Производительность)

**Результаты**
Найдена максимальная производительность системы - 45 RPS
После достижения этого RPS система перестала отвечать на запросы
Это соответствует ~ 7 сценариев покупок в секунуду 

**Цель:** Определение максимальной пропускной способности системы через постепенное увеличение нагрузки

**Конфигурация:**
- **Интенсивность:** 8 пользователей в секунду (target)
- **Количество ступеней:** 8
- **Длительность каждой ступени:** 3 минуты
- **Длительность разгона между ступенями:** 20 секунд
- **Общая длительность:** ~25 минут (3 минуты × 8 ступеней + 1 минута)

**Алгоритм нагрузки:**
1. Начинается с 0 запросов в секунду
2. Постепенно увеличивается до 1 пользователя/сек (8/8)
3. Через 20 секунд разгона достигает следующей ступени
4. Повторяется до достижения 8 пользователей/сек
5. Поддерживается максимальная нагрузка в течение 3 минут на каждой ступени

## Stability Test (Тест Стабильности)

**Цель:** Проверка стабильности системы под постоянной нагрузкой в течение продолжительного времени

**Результаты**
Система стабильно выдержала нагрузку в течении 1 часа

**Конфигурация:**
- **Целевая нагрузка:** 80% от найденной максимальной производительности системы
- **Целевая интенсивность:** 5 сценариев покупок в секунуду 
- **Длительность разгона:** 20 секунд (от 0 до 5 пользователей/сек)
- **Продолжительность стабильной нагрузки:** 1 час
- **Общая длительность:** ~1 час 20 секунд



## Сравнительный Анализ Профилей

**Max Performance Test:**
- Подходит для определения пиковой производительности
- Помогает выявить точки насыщения системы
- Полезен для планирования мощности
- Краткосрочный тест с высокой нагрузкой

**Stability Test:**
- Оценивает долгосрочную стабильность системы
- Проверяет утечки памяти и ресурсы
- Выявляет проблемы с деградацией производительности
- Подходит для приемочного тестирования
